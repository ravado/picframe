# Legacy Raspberry Pi Buster Setup

This branch is a backup of the working PictureFrame codebase for the currently
running photo frames on Raspberry Pi Zero W1 devices.

## Branch

- `backup/legacy-raspbian-buster`

## Target Device

- Raspberry Pi Zero W1
- Raspbian GNU/Linux 10 `buster`

## OS Release

Captured from `/etc/os-release` on the working device:

```ini
PRETTY_NAME="Raspbian GNU/Linux 10 (buster)"
NAME="Raspbian GNU/Linux"
VERSION_ID="10"
VERSION="10 (buster)"
VERSION_CODENAME=buster
ID=raspbian
ID_LIKE=debian
```

## Purpose

Keep this branch available as a known-good reference for the deployed legacy
photo frames before making changes for newer Raspberry Pi OS releases or newer
hardware.
